# UI prototypes

Artboards from the Claude Design canvas "Iron Cage – Redesign". They are Design Component files
(`.dc.html`) and need the Claude Design runtime (`support.js`), so they render inside Claude Design,
not as plain web pages. `canvas.json` is the canvas index with each artboard's position and title.

| File | What it shows | In the game |
|---|---|---|
| `Main.dc.html` | Fight HUD & controls | partly |
| `Hub.dc.html` | Career hub (first redesign) | yes (Classic) |
| `Result.dc.html` | Fight result screen | yes |
| `Avatars.dc.html` | Avatar creator | yes |
| `Roster.dc.html` | Avatars on fight card & rankings | yes |
| `Face.dc.html` | Avatar face component | yes |
| `HubPoster.dc.html` | A · Fight Night Poster hub | yes (Poster layout) |
| `HubConsole.dc.html` | B · Console dashboard hub | yes (Console layout) |
| `TaleOfTape.dc.html` | C · Tale of the Tape pre-fight screen | yes |
