# Ground game – plan

Guiding idea: **the ground is a tactical risk, not a replacement for striking.**
A takedown should pay off, but cost a lot and be able to fail.

## Phase 0 – before (in progress)

- [x] Xbox controller works on the Mac (fullscreen, on-screen keyboard, list navigation)
- [ ] Collect fight logs – data basis for balancing (every career fight is now logged)
- [ ] Design overhaul – prototypes in `design/prototypes/` (Poster hub, Console hub, Tale of the Tape are in the game)

## Phase 1 – takedowns

- New action: SHOOT (takedown)
- Sprawl: timing defence, similar to ducking
- A missed shot costs a lot of stamina and opens you up for counters
- Easier against the cage – cage position matters more
- Top: control + ground & pound · Bottom: stand up
- Referee stands both fighters up after ~10 s without action

## Phase 2 – positions

- Position ladder: Guard → Half guard → Side control → Mount / Back
- **Tactics, not mini-games:** in each exchange both fighters pick an intent
- Top: pass · strike · control
- Bottom: frame · cover · stand up · sweep
- Read & counter: framing stops passing, covering stops strikes
- Control time counts on the judges' scorecards

## Phase 3 – submissions & classes

- Submissions (choke, armbar …) from top and from guard
- New stat for the ground (one stat, name still open)
- New classes: Wrestler (Dagestani style) · BJJ specialist
- Re-rate real-world fighters and legends
- New win method "via submission" in news and stats
